# Davis Instruments Workforce Optimization Model

## Overview
A linear programming and operations research model designed to minimize total labor and training costs across a 6-month staffing horizon for Davis Instruments[cite: 2].

## Key Results & Strategy
- **Optimized Plan:** Achieved a total minimized cost of **$313,525** across 43 total hires using a mixed-strategy dominated by Option 3 (3-month contracts)[cite: 2].
- **Cost Efficiency:** Leveraged flat $875 training fees over longer contract lengths to balance budget limits while using shorter-term options to handle monthly demand spikes[cite: 2].
